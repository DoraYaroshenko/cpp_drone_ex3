This is a table of common issues the drone program might encounter over the runs. You are required to
handle the Mandatory ones only. The optional ones might achieve a bonus.
The targets are which objects should handle the issue. For example, if we throw an exception, the target(s)
catches it.
Gracefully handling issues is not that we don't throw an exception, is that we adjust our behavior to correct
the issue or continue despite it. For example, we might separate a command into 2, log the occurance as a
warning and try to keep running.
Choosing the N value (number of tries, see below) is up to the implementation.
